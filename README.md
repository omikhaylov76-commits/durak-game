# Дурак — тёплый вечер

Карточная игра «Дурак» с сетевым режимом. Играйте с друзьями через интернет: создайте комнату, поделитесь кодом — и все за одним столом.

## Быстрый старт

```bash
git clone https://github.com/omikhaylov76-commits/durak-game.git
cd durak-game
npm install
npm start
```

Откройте http://localhost:3737

## Как играть

1. **С ботами:** введите имя, выберите настройки, нажмите «Сесть за стол»
2. **С друзьями:** нажмите «Создать комнату» → продиктуйте код → «Начать партию»
3. **Войти в комнату:** нажмите «Войти по коду» → введите код → ждите старта

## Архитектура

- **Сервер** — авторитетный источник истины. Проверяет все ходы, раздаёт карты, каждому игроку отправляет только его руку
- **Клиент** — HTML/JS, подключается через WebSocket
- **Безопасность:** `textContent` вместо `innerHTML`, комнаты по случайному 6-значному коду, сервер проверяет принадлежность хода игроку

## Разработка

```bash
npm test              # unit-тесты игровой логики (19 тестов)
node scripts/autoplay.mjs  # автопартии ботов через WebSocket (6 конфигураций)
```

2. Выберите `omikhaylov76-commits/durak-game`

### Любой Node.js-хостинг

```bash
PORT=3737 node src/server/index.js
```

Сервер раздаёт клиентские файлы статически и принимает WebSocket-подключения на том же порту.
